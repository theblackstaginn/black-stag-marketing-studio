Meta developer app setup

The secure BSMS bridge is deployed, but Meta still needs an app owned by you. Keep the app secret in Supabase only. Never paste it into ChatGPT or commit it to GitHub.

  • Create or open a Meta developer app and add the products needed for Facebook Login and the Marketing API.
  • Add the exact callback URL below to the app's allowed OAuth redirect URIs.
  • Use the app dashboard's currently supported Graph API version.
  • Store the values in Supabase Edge Function secrets as META_APP_ID, META_APP_SECRET, and META_GRAPH_VERSION.

Callback URL:

https://theblackstaginn.github.io/black-stag-marketing-studio/meta-connect.html

The Meta token is encrypted with AES-256-GCM before storage. Browser code receives only sanitized connection and ad-account metadata. The OAuth token itself never returns to this page.
